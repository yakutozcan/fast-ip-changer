# Screenshots

This directory holds the screenshots referenced from the top-level README. They are not
generated by the build — the app has to be running, so they are captured by hand and
committed.

| File | What it shows | Present |
| --- | --- | --- |
| `ip-config.png` | The "IP Yapılandırma" tab with an adapter selected. | yes |
| `diagnostics.png` | The "Ping & Traceroute" tab with ping output in the console area. | yes |
| `adapters.png` | The adapter management modal ("Tüm Adaptörleri Yönet"). | not captured yet |

Both committed shots were taken on macOS, from a real build (`wails build`, then launch
`build/bin/fast-ip-changer.app`).

Keep them at the window's own size — the window is a fixed 480x780 panel, so a
window-only capture needs no cropping and stays readable inline. On macOS use
<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>4</kbd> then <kbd>Space</kbd> to capture just the
window; on Windows use <kbd>Alt</kbd>+<kbd>PrtScn</kbd>. The top-level README scales them
down with an `<img width>` so the table cells stay a sensible size; that means a Retina
capture is fine, and preferable to a downscaled one.

Do not include a real network's addressing beyond a private RFC 1918 address. The
committed `ip-config.png` shows a `10.10.2.x` adapter address, which is private and
non-routable; a public address, or a hostname naming a real site, does not belong here.

They are referenced from the README like this:

```markdown
| IP configuration | Diagnostics |
| --- | --- |
| <img src="docs/screenshots/ip-config.png" width="380"> | <img src="docs/screenshots/diagnostics.png" width="380"> |
```

Screenshots live here rather than in `build/` on purpose: `build/` is scanned by Wails for
icon assets, and `docs/` is not embedded into the binary, so images here cost nothing at
runtime.
