# Screenshots

This directory holds the screenshots referenced from the top-level README. They are not
generated by the build — the app has to be running, so they are captured by hand and
committed.

Capture three, at these names, from a real build (`wails build`, then launch
`build/bin/fast-ip-changer.app` or the installed `.exe`):

| File | What to show |
| --- | --- |
| `ip-config.png` | The "IP Yapılandırma" tab with an adapter selected and a profile loaded. |
| `diagnostics.png` | The diagnostics tab with ping output in the console area. |
| `adapters.png` | The adapter management modal. |

Keep them at the window's own size — the window is a fixed 480x780 panel, so a
window-only capture needs no cropping and stays readable inline. On macOS use
<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>4</kbd> then <kbd>Space</kbd> to capture just the
window; on Windows use <kbd>Alt</kbd>+<kbd>PrtScn</kbd>.

Do not include a real network's addressing. The three profiles the app ships with
(`DF_192.168.1.100` and friends) are generic RFC 1918 examples and are fine to show.

Then reference them from the README, under the intro:

```markdown
| IP configuration | Diagnostics | Adapters |
| --- | --- | --- |
| ![](docs/screenshots/ip-config.png) | ![](docs/screenshots/diagnostics.png) | ![](docs/screenshots/adapters.png) |
```

Screenshots live here rather than in `build/` on purpose: `build/` is scanned by Wails for
icon assets, and `docs/` is not embedded into the binary, so images here cost nothing at
runtime.
